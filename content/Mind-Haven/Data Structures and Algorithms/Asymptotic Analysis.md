Asymptotic analysis is fundamental concept in computer science that helps us understand how algorithms performs as input size increases, it focuses on the behaviour of algos 'at the limit' rather than their exact performance for specific inputs, allowing us to compare algorithms effectively.

## [[Logarithms]]
Crucial in analysing divide-and-conquer algos and search operations, 
Represent algorithms that reduce their problem size by some factor in each step.
e.g. Binary search has $O(logn)$ complexity because it halves the search space in each step
Logarithms grow very slowly compared to linear or polynomial functions, making them desirable in algo design.

## [[Rates of growth]]
This topic deals with how different functions scale as input size increase.
Understanding this, helps selecting appropriate algos for different problem sizes.
