Training a software, known as 'model', to make predictions or generate content using data.

We feed it data, and it returns a prediction

Can be categorised as supervised, unsupervised, reinforcement, or generative AI


## Supervised learning
labelled data to make predictions, often for regression (predicting numerical values) or classification (categorising data)



## Unsupervised learning
Identifies patterns in unlabeled data, commonly using clustering to group similar data points

## Generative AI
Creates new content such as text, images, or music, by learning patterns from existing data and mimicking them
