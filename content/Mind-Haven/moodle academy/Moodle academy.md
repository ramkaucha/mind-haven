## Moodle Developer Basics program and certificate

[[Setting up Moodle Development Environment]]
Setting up Moodle Development environment using the official docker provided by Moodle_HQ. The course taught it using XAMPP, however modern way would be to use a docker.

[[IDE development environment]]
Setting up the extensions required for the IDE. Made personal script, which makes it easier to install all the required extensions.

[[Creating Plugin]]
Using the skeleton generator to create a skeleton file for a plugin, it seems that the skeleton generator was a old, and I did run into a couple of issues when creating.

[[Web Output Essentials]]
How to properly structure moodle local plugin type and the layout of the pages and the output APIs. 

[[Moodle's Modular Architecture and APIs]]
Shows the most commonly used APIs, how to add a link to the navigation system, handling HTTP requests, reading user submitted data.

[[Moodle Access & Security Essentials]]
Access control of plugin, using capabilities. Different types of cyber security, how to make the plugins attack proof, as much as possible.

[[Accessible Development Practices]]
How to make the pages more accessible, the accessibility standard that moodle uses.

[[Unit Testing in Moodle]]
Guidelines to follow when unit testing the plugin.

6 programs to complete, focusing on database access, page layouts, using #javascript , mobile app compatibility, and moodle development practice.
